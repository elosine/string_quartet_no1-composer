## Standard Range

- **Lowest note:** G3 (open IV string)
- **Practical upper limit (orchestral):** ~A6 (high positions, E string)
- **Extreme upper (solo/virtuoso):** ~C7 and beyond (harmonics, high positions)

**Clef:** Treble clef exclusively. No clef changes needed.

**Note on high positions:** The violin is the most agile of the string family in high positions. The smaller instrument size makes shifting easier and high positions more accessible than on viola or cello. No thumb position — violinists use standard finger positions throughout the range.

## Position Guides — All Strings

The violin fingerboard uses half-step positions, identical in concept to the viola and cello. The violin is the **smallest** of the three, meaning finger spacing is the **narrowest** — stretches are easiest on violin. The hand span in any position covers a **perfect fourth**.

## Pizzicato Notes

- Standard pizzicato: plucked with right hand index finger
- Left-hand pizzicato: indicated with `+` above the note
- Bartók (snap) pizzicato: string pulled away and snapped back against fingerboard, indicated with ⊙ (`\snappizzicato` in LilyPond)
- Violin pizzicato is **brighter and more articulate** than viola or cello, with a quick, clear attack
- The **E string** produces a particularly bright, penetrating pizzicato — can sound metallic or "pingy" in high positions
- The **G string** produces the warmest, most resonant violin pizzicato
- Most resonant on open strings and lower positions; higher positions produce thinner, shorter-sustain tones

## LilyPond Notation Reference — Articulations & Techniques

### Open String
Indicated by a circle above the note.

**Project standard: `^\markup { \teeny "o" }`** (text "o" in teeny size)
```lilypond
g16^\markup { \teeny "o" }    % open G string (G3) ← CHOSEN
d'4^\markup { \teeny "o" }    % open D string (D4)
```

**Other options** (not currently used):
```lilypond
% g16\flageolet               % slightly larger circle (Feta font)
% g16\open                    % standard small circle (Feta font)
% g16^\markup { \circle \null }  % drawn circle (geometric)
```

### Laissez Vibrer (Let Ring)
A short tie-like curve extending right from the note, not connecting to another note. Indicates the string should keep vibrating. Effective for open string pizzicato.

**Standard l.v. tie:**
```lilypond
g16\laissezVibrer           % let ring (G3)
g16\open\laissezVibrer      % open string + let ring (can combine)
```

**Arrowhead variant** (from percussion tradition, widely recognized):
```lilypond
\override TextSpanner.style = #'line
\override TextSpanner.bound-details.left.text = #""
\override TextSpanner.bound-details.right.arrow = ##t
\override TextSpanner.bound-details.right.padding = #-1
g16\open\startTextSpan s16\stopTextSpan
```

### Staccato
Short, detached. Dot above/below the note.
```lilypond
a'16-.              % staccato (shorthand) — A4
a'16\staccato       % staccato (verbose)
```

### Tenuto
Sustained, full value. Dash above/below the note.
```lilypond
d'8.--              % tenuto (shorthand) — D4
d'8.\tenuto         % tenuto (verbose)
```

| Shorthand | Name | Symbol |

### Tuplets
```lilypond
\tuplet 5/4 { r16 a'16 c''16 bf16 r16 }     % quintuplet: 5 in the space of 4
\tuplet 6/4 { r16 d'8. r16 g16 }             % sextuplet: 6 in the space of 4
\tuplet 3/2 { g8 a8 b8 }                      % triplet: 3 in the space of 2
```

Tuplet display overrides (project standard — flat bracket, ratio numbers):
```lilypond
\override TupletBracket.bracket-visibility = ##t
\override TupletBracket.direction = #UP
\override TupletBracket.after-line-breaking = #flatten-tuplet-bracket
\override TupletBracket.padding = #0.5     % bracket height: lower = closer to notes
\override TupletNumber.text = #tuplet-number::calc-fraction-text  % shows "5:4", "6:4", etc.
\override TupletNumber.font-size = #-5
```

Individual bracket height (per-tuplet, without affecting others):
```lilypond
\once \override TupletBracket.positions = #'(11.5 . 11.5)  % both values equal = flat
\tuplet 6/4 { ... }
```

Requires `flatten-tuplet-bracket` Scheme function (defined in templates before `\score` block):
```lilypond
#(define (flatten-tuplet-bracket grob)
   (let* ((pos (ly:grob-property grob 'positions))
          (max-pos (max (car pos) (cdr pos))))
     (ly:grob-set-property! grob 'positions (cons max-pos max-pos))))
```

### Flat Beams
Force all beams to be perfectly horizontal (no slope):
```lilypond
\override Beam.damping = #+inf.0
```

## Double, Triple & Quadruple Stops

### Overview

A **double stop** plays two strings simultaneously. A **triple stop** plays three, and a **quadruple stop** plays all four. On bowed instruments, the bridge curvature means:
- **Double stops**: fully sustainable, both strings sound together
- **Triple stops**: usually broken (two strings sustain, third is caught briefly)
- **Quadruple stops**: always arpeggiated (rolled), typically bottom-to-top

For **pizzicato**, these restrictions don't apply — all strings can be plucked simultaneously.

### Violin: The Most Nimble for Double Stops

The violin is the **smallest** stringed instrument in the family, which means:
- **Narrowest finger spacing** — stretches are easier than on viola or cello
- **Seconds through octaves** are all standard technique in any position
- **Tenths** are advanced but part of standard solo repertoire (e.g., Paganini)
- **Consecutive thirds, sixths, and octaves** are fundamental violin technique — scales in these intervals are standard practice material
- The hand span covers a **perfect fourth** per position (same as viola, wider than cello's minor third, but physically easiest due to smallest fingerboard)

### Adjacent String Intervals

The open strings are tuned in **perfect fifths** (G3–D4–A4–E5). **Note: the violin has no C string** — the lowest string is G. The highest string is E, giving the violin access to higher registers than the viola.

| String Pair | Open Interval | Range of Practical Intervals |
|-------------|---------------|------------------------------|
| IV + III (G + D) | P5 (G3–D4) | m2 to ~m10 |
| III + II (D + A) | P5 (D4–A4) | m2 to ~m10 |
| II + I (A + E) | P5 (A4–E5) | m2 to ~m10 |

### Idiomatic Double Stops (Most to Least Common)

#### 1. Open String + Fingered Note (easiest)
One string is open, freeing the left hand to finger the other string freely.

| Combination | Example | LilyPond |
|-------------|---------|----------|
| Open G + fingered D string | G3 + F4 | `<g f'>` |
| Open D + fingered A string | D4 + C5 | `<d' c''>` |
| Open A + fingered E string | A4 + D5 | `<a' d''>` |
| Open E + fingered A string | E5 + D5 | `<d'' e''>` |
| Two open strings | G3 + D4 | `<g d'>` |

#### 2. Thirds and Sixths (the bread and butter)
The most common fingered double stops — consecutive runs in thirds and sixths are fundamental violin technique, more extensively developed than on any other string instrument.

**Thirds** (two fingers on adjacent strings, separated by a third):

| Position | Strings | Notes | LilyPond | Interval |
|----------|---------|-------|----------|----------|
| 1st pos | IV+III | A3 + F4 | `<a f'>` | m6 between strings → m3 |
| 1st pos | III+II | E4 + C5 | `<e' c''>` | m6 → m3 |
| 1st pos | II+I | B4 + G5 | `<b' g''>` | m6 → m3 |

**Sixths** (wider stretch, standard technique):

| Position | Strings | Notes | LilyPond | Interval |
|----------|---------|-------|----------|----------|
| 1st pos | IV+III | C4 + A4 (open) | `<c' a'>` | M6 |
| 1st pos | III+II | G4 + E5 (open) | `<g' e''>` | M6 |
| 3rd pos | II+I | E5 + C#6 | `<e'' cs'''>` | M6 |

#### 3. Perfect Fifths (one finger barred across two strings)
A single finger presses two adjacent strings at the same point.

| Position | Strings | Notes | LilyPond |
|----------|---------|-------|----------|
| 1st pos, 1st finger | IV+III | A3 + E4 | `<a e'>` |
| 1st pos, 1st finger | III+II | E4 + B4 | `<e' b'>` |
| 1st pos, 1st finger | II+I | B4 + F#5 | `<b' fs''>` |
| 3rd pos, 1st finger | II+I | C5 + G5 | `<c'' g''>` |

#### 4. Octaves (standard technique)
Same note name, one octave apart, on strings separated by one string (skip a string). **Much more accessible on violin than on viola or cello** — standard practice material. Easier in higher positions where distances shrink, but playable throughout.

| Position | Strings | Notes | LilyPond |
|----------|---------|-------|----------|
| 1st pos | IV+II | A3 + A4 (open) | `<a a'>` |
| 1st pos | III+I | E4 + E5 (open) | `<e' e''>` |
| 3rd pos | IV+II | B3 + B4 | `<b b'>` |
| 3rd pos | III+I | F#4 + F#5 | `<fs' fs''>` |

#### 5. Tenths (advanced but standard solo repertoire)
A third + an octave. Skips a string. Part of standard solo violin technique — Paganini, Wieniawski, and others use tenths extensively. Still considered advanced.

| Position | Strings | Notes | LilyPond |
|----------|---------|-------|----------|
| 1st pos | IV+II | A3 + C5 | `<a c''>` |
| 3rd pos | IV+II | B3 + D5 | `<b d''>` |
| 1st pos | III+I | E4 + G5 | `<e' g''>` |

### Idiomatic Triple Stops

Triple stops use three adjacent strings. At least one open string makes them much easier.

| Type | Example | LilyPond | Notes |
|------|---------|----------|-------|
| All open (G+D+A) | G3+D4+A4 | `<g d' a'>` | Easiest possible |
| All open (D+A+E) | D4+A4+E5 | `<d' a' e''>` | Easiest possible |
| 2 open + 1 fingered | G3+D4+B4 | `<g d' b'>` | Very easy |
| 1 open + 2 fingered | D4+B4+F#5 | `<d' b' fs''>` | Moderate |
| All fingered (1st pos) | A3+E4+C5 | `<a e' c''>` | Barré + fingered |
| Power chord shape | A3+E4+A4 | `<a e' a'>` | 5th + octave |

### Idiomatic Quadruple Stops

All four strings. Always arpeggiated. Open strings are key.

| Type | Example | LilyPond | Notes |
|------|---------|----------|-------|
| All open | G3+D4+A4+E5 | `<g d' a' e''>` | The ultimate easy quad |
| 3 open + 1 | G3+D4+A4+F#5 | `<g d' a' fs''>` | Very accessible |
| 2 open + 2 | G3+B3+D4+A4 | `<g b d' a'>` | Moderate |
| All fingered (barré) | A3+E4+B4+F#5 | `<a e' b' fs''>` | 1st finger across all 4 |
| G major chord | G3+B3+D4+G4 | `<g b d' g'>` | Classic voicing |

### LilyPond Chord Notation
```lilypond
% Double stop
<g d'>4            % G3 + D4, quarter note

% Triple stop
<g d' a'>4         % G3 + D4 + A4

% Quadruple stop (arpeggiated)
<g b d' g'>4\arpeggio    % G major chord, rolled

% With dynamics and articulations
<a e'>16-.\ff      % A3+E4 double stop, staccato, ff
```

### Stretch Guidelines

| Interval on Same String | Feasibility | Notes |
|--------------------------|-------------|-------|
| Half step (m2) | Easy | Any position |
| Whole step (M2) | Easy | Any position |
| Minor 3rd | Easy | Any position |
| Major 3rd | Easy | Any position |
| Perfect 4th | Normal technique | Standard hand span, any position |
| Augmented 4th / P5 | Extension | Requires extending 1st or 4th finger — doable |

**Key difference from cello:** The violin hand span is a perfect fourth (same as viola), compared to the cello's minor third. Combined with the narrowest fingerboard of all string instruments, the violin can reach wider intervals more comfortably than any other member of the family.

**Key difference from viola:** Same theoretical hand span (P4), but the violin's smaller fingerboard means each half step is physically smaller. This makes octaves, tenths, and fast passages in thirds/sixths noticeably easier on violin than on viola.

**Rule of thumb for stops across strings:** If both notes are reachable in the same position on their respective strings, the double stop is idiomatic. If one note requires shifting while holding the other, it's difficult or impossible.

### Pizzicato-Specific Multi-String Notes

- **Strum**: Thumb or index finger sweeps across 2–4 strings rapidly (guitar-like)
- **Pluck chord**: Thumb on lower string + index on upper string simultaneously (true double stop)
- **Three-finger pluck**: Thumb + index + middle = true triple stop pizzicato
- **E string pizzicato** is distinctly bright/metallic — consider this color when writing multi-string pizz chords
- **Pizzicato double stops are MORE accessible than bowed ones** — no bow curvature limitation
