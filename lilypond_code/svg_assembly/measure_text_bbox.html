SVG Text BBox Measurement Tool

How this works: This tool renders text in an SVG element using the exact font settings from the component library, then uses SVGElement.getBBox() to measure the precise bounding box. Results are in staff-spaces (matching the assembly engine coordinate system).

To add new text elements: Use the form below. The measurement is automatic. Copy the JSON output into svg_component_library.json under the text entry.

Prerequisite: The Crimson Pro font must be installed on this system. If the text looks wrong (wrong font), install the font from Google Fonts.
