## Session Start Ritual

Follow these steps at the beginning of every working session:

1. **Read the rubric.** Read `docs/WORKING_PRINCIPLES.md` in full. This is short and must be internalized every session.

2. **Read the progress file.** Read `docs/IMPLEMENTATION_PROGRESS.md` — focus on:
   - Current Status (top)
   - RESUME HERE (bottom)
   - The pre-implementation protocol for the current phase (if one exists)

3. **Read the pipeline plan section for the current phase.** Check `docs/STRING_QUARTET_PIPELINE_PLAN.md` §13.4 for the relevant phase plan.

4. **State your understanding back to the user.** Before doing ANY work, tell the user:
   - What phase and stage you believe we're on
   - What the next action is
   - Any principles from WORKING_PRINCIPLES.md that are especially relevant to this phase
   - Ask the user to confirm or correct

5. **Only after confirmation**, begin work.

## If resuming mid-phase
- Also read the focused stage tests for the current stage (in IMPLEMENTATION_PROGRESS.md)
- Check git status for any uncommitted work from a previous session

## If starting a new phase
- Follow the full pre-implementation protocol (§13.2.7) before writing any code
- The protocol is: System Inventory → Source Reading → Contracts → Risk Register → Staged Plan → Focused Tests → Integration Verification
