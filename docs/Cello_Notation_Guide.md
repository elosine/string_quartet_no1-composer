## Standard Range

- **Lowest note:** C2 (open IV string)
- **Practical upper limit (orchestral):** ~A5 (thumb position, A string)
- **Extreme upper (solo/virtuoso):** ~E6 and beyond (harmonics, thumb position)

## Position Guides — All Strings

The cello fingerboard uses half-step positions. Each position shifts the hand up by a half step. Fingerings shown as narrow/extended frame where applicable (e.g., Bb/B means half-step or whole-step placement of 1st finger).

Beyond 7th position, cellists typically switch to **thumb position**.

## Pizzicato Notes

- Standard pizzicato: plucked with right hand index finger
- Left-hand pizzicato: indicated with `+` above the note
- Bartók (snap) pizzicato: string pulled away and snapped back against fingerboard, indicated with ⊙ (`\snappizzicato` in LilyPond)
- Pizzicato is generally most resonant on open strings and lower positions
- Higher positions produce thinner, shorter-sustain pizzicato tones

## LilyPond Notation Reference — Articulations & Techniques

### Open String
Indicated by a circle above the note. Uses **LilyPond's built-in Feta music font** (NOT Crimson Pro or any text font).

**Project standard: `^\markup { \teeny "o" }`** (text "o" in teeny size)
```lilypond
c,16^\markup { \teeny "o" }   % open C string (C2) ← CHOSEN
g,4^\markup { \teeny "o" }    % open G string (G2)
```

**Other options** (not currently used):
```lilypond
% c,16\flageolet               % slightly larger circle (Feta font)
% c,16\open                    % standard small circle (Feta font)
% c,16^\markup { \circle \null }  % drawn circle (geometric)
```

### Laissez Vibrer (Let Ring)
A short tie-like curve extending right from the note, not connecting to another note. Indicates the string should keep vibrating (don't damp). On cello, particularly effective for open string pizzicato where the string resonates freely.

**Standard l.v. tie:**
```lilypond
c,16\laissezVibrer          % let ring
c,16\open\laissezVibrer     % open string + let ring (can combine)
```

**Arrowhead variant** (open tie with arrow — from percussion tradition, widely recognized):
```lilypond
\override TextSpanner.style = #'line
\override TextSpanner.bound-details.left.text = #""
\override TextSpanner.bound-details.right.arrow = ##t
\override TextSpanner.bound-details.right.padding = #-1
c,16\open\startTextSpan s16\stopTextSpan
```

**Text "l.v." alternative:**
```lilypond
c,16^\markup { \italic "l.v." }
```

**Combined (l.v. tie + text):**
```lilypond
c,16\laissezVibrer^\markup { \italic "l.v." }
```

**Research note:** The arrowhead l.v. tie is a legitimate notation practice from the percussion world (vibraphone, marimba, timpani). Elaine Gould's *Behind Bars* documents the standard open tie without arrowhead. The arrowhead variant is composer-specific / percussion-tradition but widely understood. George Crumb uses standard l.v. ties in *Black Angels*; arrows in his scores are primarily for directional glissandi and bowing direction. Safe to use for any string pizzicato "let ring" indication.

### Staccato
Short, detached. Dot above/below the note.
```lilypond
a16-.              % staccato (shorthand)
a16\staccato       % staccato (verbose)
```

### Tenuto
Sustained, full value. Dash above/below the note.
```lilypond
g'8.--             % tenuto (shorthand)
g'8.\tenuto        % tenuto (verbose)
```

### Articulation Shorthand Summary
| Shorthand | Name | Symbol |
|-----------|------|--------|
| `-.` | Staccato | dot |
| `--` | Tenuto | dash |
| `->` | Accent | > |
| `-!` | Marcato | ^ |
| `-^` | Marcato (alt) | ^ |
| `^\markup { \teeny "o" }` | Open string ← **CHOSEN** | o |
| `\flageolet` | Open string (alt) | ◦ |

### Tuplets
```lilypond
\tuplet 5/4 { r16 fs'16 a16 af,16 r16 }     % quintuplet: 5 in the space of 4
\tuplet 6/4 { r16 g'8. r16 c,16 }            % sextuplet: 6 in the space of 4
\tuplet 3/2 { c8 d8 e8 }                      % triplet: 3 in the space of 2
```

Tuplet display overrides (project standard — flat bracket, ratio numbers):
```lilypond
\override TupletBracket.bracket-visibility = ##t
\override TupletBracket.direction = #UP
\override TupletBracket.after-line-breaking = #flatten-tuplet-bracket
\override TupletBracket.padding = #0.5     % bracket height: lower = closer to notes
\override TupletNumber.text = #tuplet-number::calc-fraction-text  % shows "5:4", "6:4", etc.
\override TupletNumber.font-size = #-5
```

Individual bracket height (per-tuplet, without affecting others):
```lilypond
\once \override TupletBracket.positions = #'(11.5 . 11.5)  % both values equal = flat
\tuplet 6/4 { ... }
```

Requires `flatten-tuplet-bracket` Scheme function (defined in templates before `\score` block):
```lilypond
#(define (flatten-tuplet-bracket grob)
   (let* ((pos (ly:grob-property grob 'positions))
          (max-pos (max (car pos) (cdr pos))))
     (ly:grob-set-property! grob 'positions (cons max-pos max-pos))))
```

### Flat Beams
Force all beams to be perfectly horizontal (no slope):
```lilypond
\override Beam.damping = #+inf.0
```

Alternatives:
```lilypond
\override TupletNumber.visibility = ##f              % hide numbers entirely
\once \override TupletNumber.text = "7:4"            % manual per-tuplet ratio
\override TupletBracket.bracket-visibility = ##f     % hide bracket
```

## Double, Triple & Quadruple Stops

### Overview

A **double stop** plays two strings simultaneously. A **triple stop** plays three, and a **quadruple stop** plays all four. On bowed instruments, the bridge curvature means:
- **Double stops**: fully sustainable, both strings sound together
- **Triple stops**: usually broken (two strings sustain, third is caught briefly). Can sustain three if bow pressure is high and near the bridge
- **Quadruple stops**: always arpeggiated (rolled), typically bottom-to-top. Only the top two strings sustain after the roll

For **pizzicato**, these restrictions don't apply — all strings can be plucked simultaneously with the thumb and fingers, making multi-string pizzicato chords very accessible.

### Adjacent String Intervals

The open strings are tuned in **perfect fifths** (C2–G2–D3–A3). This means the "natural" interval between adjacent strings is a fifth, and fingered combinations produce intervals from unisons (high on one string + open on the next) up to roughly an octave+ depending on position and stretch.

| String Pair | Open Interval | Range of Practical Intervals |
|-------------|---------------|------------------------------|
| IV + III (C + G) | P5 (C2–G2) | P5 to ~m10 |
| III + II (G + D) | P5 (G2–D3) | P5 to ~m10 |
| II + I (D + A) | P5 (D3–A3) | P5 to ~m10 |

### Idiomatic Double Stops (Most to Least Common)

#### 1. Open String + Fingered Note (easiest)
One string is open, freeing the left hand to finger the other string freely.

| Combination | Example | LilyPond |
|-------------|---------|----------|
| Open C + fingered G string | C2 + A2 | `<c, a,>` |
| Open G + fingered D string | G2 + F3 | `<g, f>` |
| Open D + fingered A string | D3 + C4 | `<d c'>` |
| Open A + fingered D string | A3 + G3 | `<g a>` |
| Two open strings | C2 + G2 | `<c, g,>` |

#### 2. Perfect Fifths (one finger barred across two strings)
A single finger presses two adjacent strings at the same point. Very natural on cello.

| Position | Strings | Notes | LilyPond |
|----------|---------|-------|----------|
| 1st pos, 1st finger | IV+III | D2 + A2 | `<d, a,>` |
| 1st pos, 1st finger | III+II | A2 + E3 | `<a, e>` |
| 1st pos, 1st finger | II+I | E3 + B3 | `<e b>` |
| 4th pos, 1st finger | II+I | G3 + D4 | `<g d'>` |

#### 3. Thirds (comfortable stretch)
Two fingers on adjacent strings, separated by a third. Very common in cello repertoire.

| Position | Strings | Notes | LilyPond | Interval |
|----------|---------|-------|----------|----------|
| 1st pos | III+II | A2 + F3 | `<a, f>` | m6 between strings → m3 |
| 1st pos | II+I | E3 + C4 | `<e c'>` | m6 → m3 |
| 1st pos | III+II | B2 + G3 | `<b, g>` | m6 → m3 |

#### 4. Sixths (moderate stretch)
| Position | Strings | Notes | LilyPond | Interval |
|----------|---------|-------|----------|----------|
| 1st pos | III+II | C3 + A3 (open) | `<c a>` | M6 |
| 1st pos | IV+III | G2 (open) + E3 | `<g, e>` | M6 |
| 4th pos | II+I | Bb3 + G4 | `<bf g'>` | M6 |

#### 5. Octaves (large stretch, intermediate-advanced)
Same note name, one octave apart, on strings separated by one string (skip a string). Requires a wide stretch.

| Position | Strings | Notes | LilyPond |
|----------|---------|-------|----------|
| 1st pos | IV+II | D2 + D3 | `<d, d>` |
| 1st pos | III+I | A2 + A3 (open) | `<a, a>` |
| 4th pos | IV+II | F2 + F3 | `<f, f>` |

#### 6. Tenths (very large stretch, advanced)
A third + an octave. Skips a string. Demanding but used in solo repertoire.

### Idiomatic Triple Stops

Triple stops use three adjacent strings. At least one open string makes them much easier.

| Type | Example | LilyPond | Notes |
|------|---------|----------|-------|
| All open (C+G+D) | C2+G2+D3 | `<c, g, d>` | Easiest possible |
| All open (G+D+A) | G2+D3+A3 | `<g, d a>` | Easiest possible |
| 2 open + 1 fingered | C2+G2+E3 | `<c, g, e>` | Very easy |
| 1 open + 2 fingered | G2+E3+B3 | `<g, e b>` | Moderate |
| All fingered (1st pos) | D2+A2+F3 | `<d, a, f>` | All 1st finger = barré |
| Power chord shape | D2+A2+D3 | `<d, a, d>` | 5th + octave |

### Idiomatic Quadruple Stops

All four strings. Almost always arpeggiated. Open strings are key.

| Type | Example | LilyPond | Notes |
|------|---------|----------|-------|
| All open | C2+G2+D3+A3 | `<c, g, d a>` | The ultimate easy quad |
| 3 open + 1 | C2+G2+D3+B3 | `<c, g, d b>` | Very accessible |
| 2 open + 2 | C2+A2+D3+A3 | `<c, a, d a>` | Moderate |
| All fingered (barré) | D2+A2+E3+B3 | `<d, a, e b>` | 1st finger across all 4 |
| Bach-style | C2+G2+E3+C4 | `<c, g, e c'>` | C major chord |

### LilyPond Chord Notation
```lilypond
% Double stop
<c, g,>4          % C2 + G2, quarter note

% Triple stop
<c, g, d>4        % C2 + G2 + D3

% Quadruple stop (arpeggiated)
<c, g, e c'>4\arpeggio    % C major chord, rolled

% With dynamics and articulations
<d, a,>16-.\ff    % D2+A2 double stop, staccato, ff
```

### Stretch Guidelines

| Interval on Same String | Feasibility | Positions |
|--------------------------|-------------|-----------|
| Half step (m2) | Easy | Any |
| Whole step (M2) | Easy | Any |
| Minor 3rd | Comfortable | Any |
| Major 3rd | Comfortable stretch | Lower positions |
| Perfect 4th | Maximum normal stretch | 1st–4th position |
| Augmented 4th / P5 | Requires extension or shift | Low positions only |

**Rule of thumb for stops across strings:** If both notes are reachable in the same position on their respective strings, the double stop is idiomatic. If one note requires shifting while holding the other, it's difficult or impossible.

### Pizzicato-Specific Multi-String Notes

- **Strum**: Thumb or index finger sweeps across 2–4 strings rapidly (guitar-like)
- **Pluck chord**: Thumb on lower string + index on upper string simultaneously (true double stop)
- **Three-finger pluck**: Thumb + index + middle = true triple stop pizzicato
- **Rasgueado**: Flamenco-style strumming, uncommon but effective
- **Pizzicato double stops are MORE accessible than bowed ones** — no bow curvature limitation
